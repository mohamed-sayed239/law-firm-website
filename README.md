# Law Firm Website

A modern, responsive, multi-page website developed for a real law firm to present its legal services, introduce its lawyers, and provide visitors with information about the firm and consultation options.

## Overview

The website provides a structured online presence for the law firm, making it easier for potential clients to explore available legal services, learn about the legal team, read articles, and contact the firm.

## Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Multi-Page Structure:** Includes dedicated pages for the firm's services, lawyers, articles, and general information.
- **Lawyers Section:** Presents information about the firm's legal team.
- **Legal Articles:** Provides pages for browsing and viewing legal content.
- **Consultation Page:** Offers visitors a dedicated page for consultation-related information.
- **Contact Page:** Provides contact information and communication options.
- **Admin Section:** Includes a dedicated admin directory.
- **Firebase Hosting:** Deployed and hosted using Firebase Hosting.
- **Automated Deployment:** Configured GitHub Actions workflow for Firebase Hosting deployment.
